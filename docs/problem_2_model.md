## 1. 问题目标与输出

建立整个烘干过程药材温度和水分浓度变化规律的数学模型。问题 2 的论文输出限定在前 3 h：

- 时间：0.5、1.0、1.5、2.0、2.5、3.0 h；
- 到药材中心距离：0、0.5、1、1.5、2 cm；
- 温度按表 3，水分浓度按表 4。

完整结果保存到 `result2.xlsx`：

- 时间：0～10800 s，每隔 1 s；
- 距离：0～2 cm，每隔 0.1 cm；
- 温度、水分浓度分别存放在两个工作表；
- 结果保留四位小数。

## 2. 事实与假设分层

### 来自题目和附件的事实

- 药材为圆柱形，长 25 cm，半径 2 cm。
- 初始温度 28 °C，初始干基含水率 2.55 kg/kg。
- 烘房温度和水分浓度由附件 1 给出。
- 问题 2 的相关经验公式统一采用附录 3。
- 附录 3 给出密度、比热容、导热系数和水分扩散系数的经验公式。

### 新增假设

- 继续采用一维径向轴对称模型。
- 问题 2 从 `t=0` 开始统一使用附录 3 的经验公式，不在 30 min 处切换物性公式。
- 附录 3 未重新给出表面换热系数和传质系数，`h=25 W/(m²·K)`、`hm=8e-7 m/s` 继续采用附录 2。
- 问题 2 不考虑尺寸收缩，半径保持 2 cm。
- 暂不计蒸发潜热和含水率变化引起的焓输运；题目未提供潜热、汽化热和参考焓。
- 附件 1 的环境数据采用分段线性插值。

## 4. 控制方程

径向传热方程：

`rho(C) cp(C) dT/dt = (1/r) d/dr(r k(C) dT/dr)`

径向水分扩散方程：

`dC/dt = (1/r) d/dr(r D(C,T) dC/dr)`

说明：该组方程沿用题目给出的简化形式。由于密度和比热容随含水率变化，完整的开放系统能量方程还应包含含水率变化引起的焓输运和潜热项；题目未提供相应参数，因此本文不加入这些机制，并在模型局限中明确报告。

### 4.1 模型选择依据与备选模型取舍

问题 2 的核心变化是物性随含水率和温度变化。3 h 计算范围内，附录 3 给出的物性范围为：

| 物性 | 最小值 | 最大值 | 变化倍数 |
| --- | ---: | ---: | ---: |
| 密度 `rho` | 778.99 kg/m3 | 976.40 kg/m3 | 1.25 |
| 比热容 `cp` | 2823.29 J/(kg·K) | 3415.30 J/(kg·K) | 1.21 |
| 导热系数 `k` | 0.4007 W/(m·K) | 0.4830 W/(m·K) | 1.21 |
| 扩散系数 `D` | 5.5584e-9 m2/s | 1.2522e-8 m2/s | 2.25 |

因此，继续使用问题 1 的常数物性会丢失明显的状态依赖。

| 备选模型 | 不采用为主模型的原因 |
| --- | --- |
| 常数物性模型 | 3 h 内 `rho、cp、k` 变化约 20%～25%，`D` 变化约 2.25 倍 |
| 只改变 `D`、其他物性保持常数 | 会遗漏密度、比热和导热随水分流失的变化 |
| 30 min 后切换物性 | 题目要求经验公式统一采用附录 3，不要求分段切换 |
| 引入潜热和焓输运 | 题目未提供潜热、汽化热和参考焓，模型不可识别 |
| 二维/三维模型 | 与问题 1 相同的长径比依据；`L/R=12.5`，端部影响有限 |

## 5. 初始条件与边界条件

初始条件：

`T(r,0) = 28 °C`

`C(r,0) = 2.55 kg/kg`

中心对称边界：

`dT/dr = 0, dC/dr = 0, r = 0`

外表面热边界：

`-k dT/dr = h(T - T_air(t)), r = R`

外表面水分边界：

`-D dC/dr = hm(C - C_air(t)), r = R`

## 7. 离散方法

- 空间：有限体积法，节点半径 `0, 0.1, ..., 2.0 cm`；
- 内核：`dr = 0.0000625 m`；交付网格仍为每 `0.1 cm` 一个输出点；
- 时间：隐式 Euler，`dt = 1 s`；
- 非线性：Picard 迭代，容差 `1e-8`，最大迭代次数 40；
- 变系数在控制体界面使用调和平均；
- `r=0` 使用专门对称控制体；
- 每个时间步检查非有限值、负含水率、负扩散系数和非正温度。

## 8. 验收标准

1. `t=0` 时所有节点 `T=28 °C`、`C=2.55 kg/kg`。
2. 当空气温度和水分浓度等于初始药材状态时，解不随时间自发变化。
3. 空气更热、更干时，表面温度上升、含水率下降，圆心响应滞后。
4. 水分内部变化与累计边界质量通量守恒。
5. 记录离散热方程残差和 Picard 收敛误差。
6. 比较至少两组空间网格和两组时间步，关键趋势不得改变。
7. 输出结果重新读取后与内存结果一致。
8. 所有规定结果保留四位小数。
