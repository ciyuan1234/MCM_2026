## 4. 模型与数值路线

主控方程为径向传热和水分扩散：

`rho(C) cp(C) dT/dt = (1/r) d/dr(r k(C) dT/dr)`

`dC/dt = (1/r) d/dr(r D(C,T) dC/dr)`

初始条件为 `T(r,0)=28 C`、`C(r,0)=2.55 kg/kg`。中心为对称边界，表面为对流换热和对流传质边界。问题 4 使用 `xi=r/R(t)` 固定坐标变换处理移动边界。

数值设置按问区分（理由见 `docs/overview.md` 第 3 节）：问题 1、2 用 `dr=0.0000625 m`、`dt=1 s`；问题 3、4 用 `dr=0.00003125 m`、`dt=15 s`（`dt=60 s` 会触发 Picard 不收敛，`dt=30 s` 在预热段超出 `1e-3 kg/kg` 阈值）。交付网格统一为 `0.1 cm`；问题 4 的列为材料点初始距离加一列 `药材表面`。所有含温度的指数项必须使用开尔文。

## 5. Git 与多 Agent 协同

- 主分支只保存经过验证和用户确认的成果。
- 实验分支命名为 `exp/q<问题号>-<方法>-<编号>`，一个 worktree 只做一个任务卡。
- 实验从同一基线创建，禁止实验 Agent 修改主分支、附件和最终输出。
- 协调 Agent 负责复跑和审查；复核 Agent 不得复核自己的产物。
- 多个 Agent 的同意不构成证据，结论必须追溯到题目、附件或可复现运行。
- Git 初始化、合并、清理和升级权限执行均需用户明确授权。
