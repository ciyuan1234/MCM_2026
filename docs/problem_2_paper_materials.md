## 1. 问题简述

问题 2 要求建立整个烘干过程的温度和水分浓度模型，并给出前 3 h 的结果。与问题 1 相比，主要变化是内部物性不再视为常数，而是采用附录 3 给出的经验公式。

## 2. 建模思路

继续采用圆柱径向传热—水分扩散模型。温度场由变物性导热方程控制，水分场由温度和含水率依赖的扩散方程控制。表面采用对流换热和对流传质边界，初始温度和含水率由题目给定。

## 3. 数学模型

### 3.1 定义域与坐标系

药材视为一维轴对称圆柱体，定义域为 `r in [0, R]`，其中 `R=2 cm=0.02 m`。时间范围为 `0～3 h`。

### 3.2 控制方程

传热方程：

`rho(C) cp(C) dT/dt = (1/r) d/dr(r k(C) dT/dr)`

水分扩散方程：

`dC/dt = (1/r) d/dr(r D(C,T) dC/dr)`

### 3.3 初始条件和边界条件

初始条件：

`T(r,0) = 28 °C`

`C(r,0) = 2.55 kg/kg`

中心对称条件：

`dT/dr = 0, dC/dr = 0, r = 0`

表面条件：

`-k dT/dr = h(T - T_air(t))`

`-D dC/dr = hm(C - C_air(t))`

## 4. 参数与单位

附录 3：

- `rho(C) = 650 + 128C`
- `cp(C) = 1450 + 2736C/(C+1)`
- `k(C) = 0.21 + 0.38C/(C+1)`
- `D(C,T) = 2.4e-3 exp(-0.45/C) exp(-3850/T)`

边界参数：

- `h = 25 W/(m2·K)`
- `hm = 8e-7 m/s`

温度公式中的 `T` 使用 K。

## 5. 论文可用的模型叙述

问题 2 在问题 1 的径向传热—水分扩散框架上引入变物性。随着水分流失，药材密度、比热容和导热系数发生变化，水分的扩散能力同时受含水率和温度影响。因此，采用附录 3 的经验公式描述内部物性。表面换热和传质系数仍采用附录 2 给出的参数。模型不考虑尺寸收缩，也不计入题目未提供的蒸发潜热和焓输运。

## 9. 问题 2 结论

### 9.1 数值结论

3 h 后，圆心温度为 49.8494 °C，表面温度为 49.9664 °C，径向温差仅 0.1170 °C。温度场已经接近烘房热风温度，说明传热阶段基本完成。

同一时刻，圆心含水率为 1.7662 kg/kg，表面含水率为 1.0081 kg/kg，径向含水率差为 0.7581 kg/kg。表面含水率在 0.5 h 内就从初始值 2.55 降至约 1.65 kg/kg，而圆心在 0.5 h 时仍约为 2.55 kg/kg。

### 9.2 物理结论

变物性条件下，药材在前 3 h 内经历了明显的升温和表面失水。热量传递速度快于水分扩散，表面迅速升温并接近热风温度，圆心升温相对滞后，但 3 h 时温差已经很小。含水率则仍有显著径向梯度，圆心水分浓度远高于表面，说明水分扩散是后续干燥过程的主要限制。

圆心含水率 3 h 时为 1.7662 kg/kg，远高于题目后续要求的 0.15 kg/kg。因此，3 h 不足以完成整体烘干，必须进入问题 3 的长期干燥阶段。

### 9.3 验证结论

水分守恒相对误差为 2.8083e-15，离散热方程最大线性系统残差为 3.6159e-14，最大 Picard 迭代次数为 3。空间网格和时间步加密后，最大水分浓度差异为 `1.89e-5 kg/kg`，结果满足用户确认的 `0.001 kg/kg` 阈值。

### 9.4 模型局限

当前模型未计入蒸发潜热和含水率变化引起的焓输运，也未考虑尺寸收缩。变物性能量校验采用离散方程一致性，不声称完整热力学能量守恒。

## 10. 模型选择依据（论文写作素材）

问题 2 的内部物性采用附录 3。3 h 计算范围内，密度从 976.40 降至 778.99 kg/m³，比热容从 3415.30 降至 2823.29 J/(kg·K)，导热系数从 0.4830 降至 0.4007 W/(m·K)，水分扩散系数在 `5.5584e-9～1.2522e-8 m²/s` 之间变化。扩散系数的变化超过 2 倍，说明含水率和温度对水分迁移有显著影响。

因此，本文不使用常数物性模型，也不采用只修正扩散系数的简化模型。表面换热和传质系数继续采用附录 2，因为附录 3 未重新定义这两个系数。模型暂不计入题目未提供的潜热和焓输运，也不考虑问题 4 才引入的尺寸收缩。
