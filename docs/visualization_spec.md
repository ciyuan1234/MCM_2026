# 可视化规范

- 版本日期：2026-09-12
- 适用对象：论文图、答辩图和验证对比图
- 风格：论文简约风

## 基本要求

- 标签、图例、标题和图注使用中文；单位和数字使用标准符号。
- 字体栈（简体优先）：`Hiragino Sans GB` → `Songti SC` → `Heiti TC` → `Arial Unicode MS` → `DejaVu Sans`；数学符号统一走 mathtext 并使用同一字体，避免中英混排跳字与日文变体字形。
- 生成时必须检查字体是否覆盖全部汉字（自检项"图件字体覆盖全部汉字"），出现缺字即视为失败。
- 白底，去掉顶部和右侧边框，保留轻网格，线宽适中。
- 坐标轴必须写清物理量、单位和时间基准。
- 图中必须标注数据来源、模型来源和生成脚本。
- **全部图件必须为黑白（灰阶）**：竞赛要求黑白打印，禁止使用任何彩色元素，灰度之外不得出现色相差异。
- 不使用平滑线掩盖原始数据，不夸大趋势或差异。

## 黑白配色与线型

- 时间序列或顺序量使用**截断的灰阶色带**（`Greys`，亮度区间 0.30～0.95），并配 colorbar，浅→深对应时间由早到晚。
- **线型 + 标记 + 端点标注三重区分**：同一张图内不同曲线依次使用实线、虚线、点划线、点线等线型，并配圆、方、三角、菱形等标记；最早与最晚时刻在曲线端点直接标注。
- 圆心使用黑色实线加圆点标记；表面使用深灰（`#595959`）虚线加方点标记。
- 圆心与表面之间的差异用浅灰填充（`#D9D9D9`，低透明度），不得遮挡数据。
- 达标线等辅助线使用黑色点线；所有数值标注使用黑色。
- 术语统一：同一物理量在图中只使用一种称法（本文为"水分浓度（干基）"），单位与符号在标题、轴标签、图例、标注四处保持一致。
- 端点数值标注必须置于绘图区内并加白底，禁止压住坐标轴、刻度或色带。
- 验收口径：任意两条曲线在黑白复印后仍可区分（线型或标记不同），并由自检脚本检查彩色像素占比小于 1%。

## 输出格式

- 每张主图输出 `.png`、`.pdf`、`.svg`。
- PNG 使用 300 dpi，白底，`bbox_inches="tight"`。
- PDF 和 SVG 用于论文排版和后续编辑。
- 所有输出放在 `outputs/figures/`。

## 图表结构

- 问题 1 保留四张独立图，并额外生成一张 2×2 汇总图。
- 独立图负责细节，汇总图负责总览；汇总图不能替代独立图。
- 对比图只在完成正式实验后生成。

## 对比图规则

- 数值方法对比放验证章节或附录，例如隐式有限体积对显式有限差分。
- 物理模型对比放正文，例如常数物性对变物性、是否考虑收缩。
- 边界敏感性对比用范围或阴影带表示，不把多个未经确认的结果混成一条曲线。
- 对比图必须来自同一基准、同一时间网格和同一终止判据。

## 视觉审查清单

- 坐标标题和单位是否完整；
- 图例是否遮挡数据；
- 线条和标记是否可区分；
- 关键值和最终值是否可读；
- 中文是否出现方框或乱码；
- 黑白打印是否仍可区分；
- 图注、来源和图号是否齐全；
- 数据是否来自结果文件而非手工填写。

## 当前限制

自动工具可以检查文件、尺寸、标题和来源文字，但不能可靠判断主观美观。最终图件需要用户或具备图像查看能力的复核者进行视觉确认。
