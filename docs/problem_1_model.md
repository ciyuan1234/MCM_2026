## 1. 问题目标与输出

建立预热平衡阶段内药材温度和水分浓度随时间、半径变化的数学模型。

论文表格需要给出：

- 时间：100、300、600、900、1200、1500、1800 s；
- 到药材中心距离：0、0.5、1、1.5、2 cm；
- 温度结果按表 1，水分浓度结果按表 2。

完整结果保存到 `result1.xlsx`：

- 时间：0～1800 s，每隔 1 s；
- 到药材中心的距离：0～2 cm，每隔 0.1 cm；
- 数值保留四位小数。

## 2. 事实与假设分层

### 来自题目和附件的事实

- 药材为圆柱形，长 25 cm，半径 2 cm。
- 初始温度 28 °C。
- 初始干基含水率 2.55 kg/kg。
- 烘房温度和水分浓度由附件 1 给出。
- 问题 1 的相关参数由附录 2 给出。

### 新增假设

- 长径比较大，忽略两端效应，只研究半径方向的一维轴对称问题。
- 预热阶段 30 min 内物性取常数。
- 初始温度和含水率在半径方向均匀分布。
- 内部无热源、无化学反应。
- 热量和水分的传递沿半径方向，中心对称。
- 暂不加入蒸发潜热项；题目未提供潜热参数，后续如需加入必须单独确认。
- 附件 1 的环境数据在时间上采用分段线性插值。

### 3.1 单位约定

题目和附件 2 给出的半径与距离使用 cm，计算内核使用 SI 单位 m。输入、内核和输出之间的转换必须显式完成：

| 量 | 题目/附件单位 | 内核单位 | 输出单位 | 转换 |
| --- | --- | --- | --- | --- |
| 半径 `R` | cm | m | cm | `R_m = R_cm / 100` |
| 到中心距离 `r` | cm | m | cm | `r_m = r_cm / 100` |
| 温度 `T` | °C | K | °C | `T_K = T_C + 273.15` |
| 时间 `t` | s 或 h | s | s 或 h | `t_s = 3600 * t_h` |
| 水分浓度 `C` | kg/kg | kg/kg | kg/kg | 不变 |

问题 1 的几何转换明确为：

`R = 2 cm = 0.02 m`

`r = 0～2 cm = 0～0.02 m`

输出模板仍按题目要求使用 cm。

## 4. 控制方程

圆柱径向传热方程：

`rho cp dT/dt = (1/r) d/dr(r k dT/dr)`

径向水分扩散方程：

`dC/dt = (1/r) d/dr(r D(C) dC/dr)`

问题 1 中密度、比热容和导热系数取常数，扩散系数只依赖水分浓度。

### 4.2 模型选择依据

题目要求给出药材内部温度和水分浓度的时空变化，并提供了圆柱几何、初始条件、表面换热系数 `h`、表面传质系数 `hm`、密度 `rho`、比热容 `cp`、导热系数 `k` 以及扩散系数 `D(C)`。这些信息直接对应连续介质中的非稳态导热与扩散问题，而不是只有外部环境数据的经验回归问题。

模型推导链如下：

1. 能量守恒 + Fourier 导热定律 → 圆柱径向传热方程；
2. 质量守恒 + Fick 扩散定律 → 圆柱径向水分扩散方程；
3. 轴对称 → `r=0` 处零通量；
4. 题目给出的 `h`、`hm` → 表面 Robin 边界；
5. 题目给出的 `D(C)` → 采用浓度依赖扩散系数；
6. 题目问题 1 的附录 2 → 采用常数物性。

量化指标如下：

| 指标 | 数值 | 含义 |
| --- | ---: | --- |
| 热扩散率 `alpha = k/(rho cp)` | `1.6886e-7 m2/s` | 温度扩散速度 |
| 热渗透深度 `sqrt(alpha t)` | `1.7434 cm` | 30 min 内热影响深度 |
| 初始水分扩散系数 `D(2.55)` | `4.9377e-9 m2/s` | 水分扩散速度 |
| 水分渗透深度 `sqrt(D t)` | `0.2981 cm` | 30 min 内水分影响深度 |
| 热 Biot 数 `Bi = hR/k` | `1.3889` | 内部导热和表面换热都重要，不能集总 |
| Fourier 数 `Fo = alpha t/R2` | `0.7598` | 预热阶段处于明显瞬态过程 |
| 传质 Biot 数 `hm R / D` | `3.2404` | 表面传质和内部扩散都不可忽略 |
| 长/半径 `L/R` | `12.5` | 径向一维近似合理 |
| 长/直径 `L/(2R)` | `6.25` | 之前“长径比 6.25”的明确定义 |

备选模型取舍：

| 备选模型 | 不采用为主模型的原因 |
| --- | --- |
| 集总参数模型 | `Bi=1.39`，内部径向梯度不可忽略 |
| 稳态模型 | `Fo=0.76`，预热阶段是瞬态问题 |
| 直接指定表面温度或浓度 | 题目给出 `h`、`hm`，应使用 Robin 边界 |
| 常数扩散系数 | 题目已经给出 `D(C)`，不应额外丢弃该信息 |
| 二维或三维模型 | `L/R=12.5`，热渗透深度约 1.74 cm，端部影响有限 |
| 含蒸发潜热模型 | 题目未给潜热或相变参数，模型不可识别 |
| 纯数据拟合或机器学习 | 附件没有药材内部温度和含水率观测，无法训练内部场模型 |

因此，当前模型是题目条件下最小、可识别且物理一致的基准模型。它不声称是唯一正确模型，也不在缺少内部实测数据时声称经验精度。

## 5. 初始条件与边界条件

初始条件：

`T(r,0) = 28 °C`

`C(r,0) = 2.55 kg/kg`

中心对称边界：

`dT/dr = 0, dC/dr = 0, r = 0`

外表面热边界：

`-k dT/dr = h(T - T_air(t)), r = R`

外表面水分边界：

`-D dC/dr = hm(C - C_air(t)), r = R`

## 6. 参数来源

附录 2 给出：

- `rho = 820 kg/m3`
- `cp = 2600 J/(kg·K)`
- `k = 0.36 W/(m·K)`
- `h = 25 W/(m2·K)`
- `hm = 8e-7 m/s`
- `D = 7e-9 exp(-0.89/C) m2/s`

其中 `C` 为药材水分浓度，单位 kg/kg。

## 7. 离散方法

- 空间采用有限体积法，节点半径取 `0, 0.1, 0.2, ..., 2.0 cm`。
- 计算内核统一转换为米：`Delta r = 0.0000625 m`；交付网格仍为每 `0.1 cm` 一个输出点。
- `r=0` 使用专门的对称控制体，不能直接代入 `1/r`。
- 时间采用隐式 Euler。
- 问题 1 基准时间步长取 `1 s`，用于生成完整结果。
- 变系数在控制体界面上取调和平均。
- 每个时间步需要检查温度、含水率、扩散系数和半径的有限性与非负性。

## 8. 验收标准

1. `t=0` 时，所有节点 `T=28 °C`、`C=2.55 kg/kg`。
2. 当空气温度和水分浓度等于初始药材状态时，解不随时间自发变化。
3. 空气更热时，药材整体呈升温趋势；空气更干时，表面含水率下降并产生径向梯度。
4. 比较至少两组空间网格和两组时间步长，报告关键输出相对变化。
5. 比较内部能量/水分变化与累计边界通量，报告收支误差。
6. 输出结果重新读回，与内存结果逐项比对。
7. 所有规定结果保留四位小数。
