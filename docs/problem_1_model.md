## 1. 问题目标与输出

建立预热平衡阶段内药材温度和水分浓度随时间、半径变化的数学模型。

论文表格需要给出：

- 时间：100、300、600、900、1200、1500、1800 s；
- 到药材中心距离：0、0.5、1、1.5、2 cm；
- 温度结果按表 1，水分浓度结果按表 2。

完整结果保存到 `result1.xlsx`：

- 时间：0～1800 s，每隔 1 s；
- 到药材中心的距离：0～2 cm，每隔 0.1 cm；
- 数值保留四位小数。

## 2. 事实与假设分层

### 来自题目和附件的事实

- 药材为圆柱形，长 25 cm，半径 2 cm。
- 初始温度 28 °C。
- 初始干基含水率 2.55 kg/kg。
- 烘房温度和水分浓度由附件 1 给出。
- 问题 1 的相关参数由附录 2 给出。

### 新增假设

- 长径比较大，忽略两端效应，只研究半径方向的一维轴对称问题。
- 预热阶段 30 min 内物性取常数。
- 初始温度和含水率在半径方向均匀分布。
- 内部无热源、无化学反应。
- 热量和水分的传递沿半径方向，中心对称。
- 暂不加入蒸发潜热项；题目未提供潜热参数，后续如需加入必须单独确认。
- 附件 1 的环境数据在时间上采用分段线性插值。

## 4. 控制方程

圆柱径向传热方程：

`rho cp dT/dt = (1/r) d/dr(r k dT/dr)`

径向水分扩散方程：

`dC/dt = (1/r) d/dr(r D(C) dC/dr)`

问题 1 中密度、比热容和导热系数取常数，扩散系数只依赖水分浓度。

## 5. 初始条件与边界条件

初始条件：

`T(r,0) = 28 °C`

`C(r,0) = 2.55 kg/kg`

中心对称边界：

`dT/dr = 0, dC/dr = 0, r = 0`

外表面热边界：

`-k dT/dr = h(T - T_air(t)), r = R`

外表面水分边界：

`-D dC/dr = hm(C - C_air(t)), r = R`

## 6. 参数来源

附录 2 给出：

- `rho = 820 kg/m3`
- `cp = 2600 J/(kg·K)`
- `k = 0.36 W/(m·K)`
- `h = 25 W/(m2·K)`
- `hm = 8e-7 m/s`
- `D = 7e-9 exp(-0.89/C) m2/s`

其中 `C` 为药材水分浓度，单位 kg/kg。

## 7. 离散方法

- 空间采用有限体积法，节点半径取 `0, 0.1, 0.2, ..., 2.0 cm`。
- 计算内核统一转换为米：`Delta r = 0.001 m`。
- `r=0` 使用专门的对称控制体，不能直接代入 `1/r`。
- 时间采用隐式 Euler。
- 问题 1 基准时间步长取 `1 s`，用于生成完整结果。
- 变系数在控制体界面上取调和平均。
- 每个时间步需要检查温度、含水率、扩散系数和半径的有限性与非负性。

## 8. 验收标准

1. `t=0` 时，所有节点 `T=28 °C`、`C=2.55 kg/kg`。
2. 当空气温度和水分浓度等于初始药材状态时，解不随时间自发变化。
3. 空气更热时，药材整体呈升温趋势；空气更干时，表面含水率下降并产生径向梯度。
4. 比较至少两组空间网格和两组时间步长，报告关键输出相对变化。
5. 比较内部能量/水分变化与累计边界通量，报告收支误差。
6. 输出结果重新读回，与内存结果逐项比对。
7. 所有规定结果保留四位小数。
