## 1. 问题目标与输出

确定烘房在长期烘干阶段需要持续多久，才能使药材各处水分浓度均降到 `0.15 kg/kg` 以下。

形式化定义：

`t_f = min { t : max over r of C(r,t) <= 0.15 kg/kg }`

输出：

- 结论：烘干时间 `t_f`（单位 h，保留四位小数），以及用于论文的物理解释；
- 论文表 5：时间每 6 h 至结束、到中心距离每 0.5 cm 的水分浓度；
- `result3.xlsx`：`Sheet1` 填水分浓度，时间 0～结束、间隔 60 s，距离 0～2 cm、间隔 0.1 cm，保留四位小数；
- `result3_solution.json`：完整数值结果（本地生成，按 G-029 不纳入版本控制）。

- 终止判据为“各处水分浓度低于 0.15 kg/kg”。

## 4. 控制方程与边界条件

与问题 2 完全一致：

`rho(C) cp(C) dT/dt = (1/r) d/dr(r k(C) dT/dr)`

`dC/dt = (1/r) d/dr(r D(C,T) dC/dr)`

初始条件：

`T(r,0) = 28 °C`，`C(r,0) = 2.55 kg/kg`

中心对称与表面 Robin 边界：

`dT/dr = dC/dr = 0, r = 0`

`-k dT/dr = h(T - T_air(t)), r = R`

`-D dC/dr = hm(C - C_air(t)), r = R`

## 5. 附录 3 物性与取值区间

| 物性 | 公式 | 单位 |
| --- | --- | --- |
| 密度 | `rho = 650 + 128C` | kg/m³ |
| 比热容 | `cp = 1450 + 2736 C/(C+1)` | J/(kg·K) |
| 导热系数 | `k = 0.21 + 0.38 C/(C+1)` | W/(m·K) |
| 扩散系数 | `D = 2.4e-3 exp(-0.45/C) exp(-3850/T)`，`T` 取 K | m²/s |

问题 3 的含水率要跨过 `0.15 kg/kg`，因此扩散系数的取值范围远大于问题 2：

| 状态 | `D`（m²/s） | 说明 |
| --- | ---: | --- |
| `C=2.55`、`T=323.15 K` | `1.33e-8` | 初始状态 |
| `C=1.0`、`T=323.15 K` | `1.01e-8` | 中间阶段 |
| `C=0.15`、`T=323.15 K` | `7.9e-10` | 达标阈值附近 |

即在整个干燥区间内 `D` 下降约 17 倍，晚期干燥由内部扩散控制。这是问题 3 与问题 2 的主要差别，也是本问必须做长时程网格与时间步收敛检查的原因。

对 `C→0`，`exp(-0.45/C)→0`，公式在数学上趋于 0 而不是发散；实现中仍按 `AGENTS.md` 检查负扩散系数和非有限值并报错。

## 6. 长期边界的处理

附件 1 只覆盖 `0～14400 s`（4 h），问题 3 的求解时间远超该范围。

采用的处理：`t <= 14400 s` 用分段线性插值；`t > 14400 s` 保持末值

`T_air = 50.165 °C`，`C_air = 0.04986 kg/kg`

依据（附件 1 自身数据，不是外推）：空气温度在约 2 h 后已稳定在 `49.8～50.2 °C` 区间波动（`t=7200 s` 起为 49.85、49.93、49.92、49.89、49.91、50.20、49.81、49.76、49.82、50.07、50.17 °C），空气水分浓度同期稳定在 `0.0498～0.0503 kg/kg`。末值落在该平台内，因此“保持末值”是平台值的取用，而不是趋势外推。

残余不确定性（真实烘房长期可能存在小幅波动或逐步降温）由 EXP-002 长期边界敏感性实验量化，见决策日志。

## 7. 终止判据与最慢达标位置

题目要求“各处水分浓度均低于 0.15 kg/kg”。水分由内向外扩散，圆心是最后达标位置，因此判据取

`C(0, t_f) = 0.15 kg/kg`

但该等价性不能默认成立，必须数值验证：

1. 逐时刻检查 `argmax_r C(r,t) = 0`（圆心是空间最大值）；
2. 检查 `C(0,t)` 随时间单调下降。

两项检查将在正式运行中以测试锁定；可行性探针中“圆心在每一步都是空间最大值”为真。

`t_f` 报告两个口径：

- `t_f_grid`：输出网格（60 s）上首次满足判据的时刻，用于 `result3.xlsx` 的时间范围；
- `t_f_interp`：在跨越判据的两个相邻时刻之间线性内插得到的时刻，用于论文结论。

两者差值不超过一个输出间隔（60 s），论文同时给出四舍五入到 0.0001 h 的结果。

## 8. 离散方法与数值设置

- 空间：有限体积法，圆心使用专门对称控制体，界面扩散系数用调和平均；
- 空间步长：`dr = 0.00003125 m`（问题 3 专用；问题 1、2 的生产网格仍为 `0.0000625 m`，不受影响）；
- 时间：隐式 Euler，`dt = 15 s`；
- 非线性：Picard 迭代，容差 `1e-8`，最大迭代次数 40，不收敛必须报错终止，不得暗中放宽容差；
- 输出抽样：`result3.xlsx` 每 60 s 取一个时间点（每 2 个时间步），距离按 0.1 cm 抽取；
- 能量与质量检查：水分用内部变化对边界通量；热量使用离散热方程残差（沿用问题 2 的 G-021 口径），不使用问题 1 的积分口径。

### 8.1 时间步的三步取值过程

1. `dt = 60 s`：可行性探针在 `dr = 0.25 mm` 时于 `t = 75480 s` 抛出 `PicardConvergenceError`。这是非线性迭代失效，不是可以放宽容差的情形，必须缩小时间步。
2. `dt = 30 s`：所有测试网格均可收敛，但预热段精度不达标。以 `dt = 5 s` 为参考，在 `dr = 0.0625 mm` 下 0.5 h 表面含水率偏差 `2.28e-3 kg/kg`，超过用户确认的 `1e-3 kg/kg` 阈值；6 h 偏差 `6.7e-4 kg/kg`。
3. `dt = 15 s`：同一比较下 0.5 h 偏差降到 `9.1e-4 kg/kg`，6 h 偏差 `2.7e-4 kg/kg`，全部满足阈值。生产时间步取 15 s。

时间步研究数据（`dr = 0.0625 mm`，相对 `dt = 5 s` 参考的最大含水率偏差）：

| 时间步 | 0.5 h 表面 | 2 h 表面 | 6 h 圆心 |
| --- | ---: | ---: | ---: |
| 30 s | `2.28e-3` | `3.23e-4` | `6.73e-4` |
| 15 s | `9.12e-4` | `1.29e-4` | `2.69e-4` |
| 7.5 s | `2.28e-4` | `3.2e-5` | `6.7e-5` |

## 9. 数值收敛证据（可行性探针）

正式收敛证据由 `analysis/q3_convergence.py` 生成并写入 `outputs/q3_convergence.json` 与 `outputs/q3_convergence_table.md`。

圆心达到 0.15 kg/kg 的时刻 `t_f`（`dt=15 s`，除最后一行）：

| 空间步长 | `t_f` (h) | 相邻差 (h) |
| --- | ---: | ---: |
| `0.125 mm` | 60.2289 | — |
| `0.0625 mm` | 57.5779 | 2.6510 |
| `0.03125 mm`（生产） | 57.2506 | 0.3273 |
| `0.015625 mm` | 57.1967 | 0.0539 |
| `0.03125 mm`，`dt=30 s` | 57.2636 | 时间步差 0.0131 |

读法与结论：

1. 空间收敛：生产网格相对 `0.015625 mm` 的 `t_f` 差为 `0.0539 h`（阈值 0.5 h），6 h 采样含水率场的最大差为 `3.754e-4 kg/kg`（阈值 `1e-3`）。
2. 时间收敛：`dt=15 s` 与 `dt=30 s` 的 `t_f` 差为 `0.0131 h`（阈值 0.0167 h）。
3. 相邻差 `2.6510 → 0.3273 → 0.0539 h` 逐次缩小约 6～8 倍，说明收敛是单调加速的。
4. 早期用过的粗网格 `dr=0.5 mm` 给出 226.7 h（约 9.4 天），偏差约 4 倍，属严重欠分辨；**不能**用粗网格结果作答案。
5. 量级检查：正式结论 `t_f = 57.2667 h`（约 2.4 天）。这与解析笔记中“恒温阶段持续 2～3 天”的描述同量级；注意笔记不是题目事实，此处仅作量级交叉检查。
6. 水分守恒相对误差 `1.54e-14`，离散残差 `3.93e-13`。热量积分口径的相对误差约 62%（问题 2 为 17.6% 的同类假误差），故热量采用离散残差口径。

## 10. 模型选择依据与备选模型取舍

| 备选模型 | 不采用为主模型的原因 |
| --- | --- |
| 常数物性（问题 1 模型） | 含水率从 2.55 降到 0.15，`rho、cp、k` 变化显著、`D` 变化约 17 倍 |
| 只改变 `D`、其余物性取常数 | 与附录 3 给出的公式体系不一致，且无法解释长时程物性变化 |
| 以表面含水率作为达标判据 | 题目要求“各处达标”，表面最先达标，会显著低估烘干时间 |
| 以平均含水率作为达标判据 | 同样会低估；圆心是控制点 |
| 稳态或集总模型 | 长时程干燥仍由内部扩散控制，内部梯度不可忽略 |
| 引入潜热与焓输运 | 题目未提供潜热、汽化热和参考焓，参数不可识别；作为局限报告 |
| 引入尺寸收缩 | 属问题 4；问题 3 先固定半径，避免两问边界重叠 |
| 粗网格长时程快算 | 探针显示 `dr=0.5 mm` 的 `t_f` 偏差约 4 倍，结论会翻转 |

## 11. 验收标准

1. `t=0` 全部节点 `T=28 °C`、`C=2.55 kg/kg`。
2. 零驱动（空气状态等于药材初始状态）时解不随时间变化。
3. 趋势检查：表面先失水，圆心滞后；空气更热更干时失水更快。
4. 逐时刻验证圆心是空间最大含水率位置，且 `C(0,t)` 单调下降。
5. 水分守恒：内部水分变化与累计边界通量一致；热量报告离散热方程残差。
6. 空间收敛：以生产网格 `dr = 0.03125 mm` 对更细网格 `dr = 0.015625 mm` 验收，阈值 `|Δt_f| <= 0.5 h`、最大含水率差 `<= 0.001 kg/kg`；`dr = 0.0625/0.125 mm` 只作为收敛趋势报告。
7. 时间收敛：`dt = 15 s` 对 `dt = 30 s`，阈值 `|Δt_f| <= 0.0167 h`（1 个输出间隔）。
8. 小规模确定性回归算例保持稳定。
9. `result3.xlsx` 回读值与内存结果一致；模板表头、行列顺序和单位不变。
10. 结论中的 `t_f` 与关键含水率值必须能追溯到结果文件（由测试锁定）。

## 13. 风险与待确认

- **长期边界**：`t > 14400 s` 的实际烘房状态未知，是问题 3 最主要的系统不确定性，需 EXP-002 量化。
- **潜热缺省**：不计蒸发潜热会使药材温度偏高、干燥偏快，属系统性偏差方向已知但幅度未量化（GAP-025）。
- **附录 3 的低含水率外推**：`D(C,T)` 在 `C < 0.2` 区间没有实测支持，只按题目公式计算。
- **非线性求解稳健性**：`dt=60 s` 已出现不收敛，正式运行时若在 `dt=30 s` 仍不收敛，必须先报告再决定是否细化时间步或改进迭代，不得放宽容差。
- **网格分辨率**：最初的生产网格 `0.0625 mm` 在 r=1.7～1.9 cm、24～58 h 的近表面带相对更细网格偏差达 `2.27e-3 kg/kg`，超过 `1e-3` 阈值，因此细化为 `0.03125 mm`；细化后的实测偏差见第 9 节。
- **题目原文核对**：本机无法直接抽取 PDF 中文正文（字体为无 ToUnicode 的 CID 编码），问题 3 的中文表述（包括是否给出2～3天的时长提示）需用户确认。
