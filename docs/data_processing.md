# 数据处理策略与证据

- 版本日期：2026-09-11
- 适用数据：`附件/附件1.xlsx`、`附件/附件2.xlsx`
- 关联文档：`docs/data_dictionary.md`、`docs/decision_log.md`、`docs/experiments/EXP-001-data-processing-sensitivity/brief.md`

## 1. 结论

附件数据当前不需要破坏性清洗。处理原则是“只校验、不改值”，仅进行单位转换、时间插值和输出舍入。原始附件始终只读。

## 2. 数据特点与时间分析

| 数据 | 特点 |
| --- | --- |
| 附件 1 时间 | 241 个数据点，0～14400 s，严格按 60 s 递增 |
| 附件 1 温度 | 28～50.246 °C，趋势性升温，局部波动不超过 0.8 °C |
| 附件 1 水分浓度 | 0.01963～0.05025 kg/kg，非负且无跳变 |
| 附件 2 时间 | 145 个数据点，0～259200 s，严格按 1800 s 递增，覆盖 72 h |
| 附件 2 半径 | 2～1.198 cm，整体非增，最大单步下降 0.127 cm；92 个时间步保持不变 |

完整性和局部异常检查：

- 无缺失值、重复时间戳、时间倒序或非有限值。
- 对原始值做全局稳健离群检测会受到长期趋势干扰，不能直接作为清洗依据。
- 对一阶差分做稳健检测，`|z|>3.5` 的点为 0。

## 3. 清洗决策

| 项目 | 决策 | 原因 |
| --- | --- | --- |
| 缺失值 | 不插补 | 当前没有缺失；未来出现时停止计算并报告 |
| 重复时间戳 | 不去重 | 当前没有重复 |
| 时间倒序 | 不排序修复 | 当前严格递增 |
| 温度、水分浓度波动 | 不平滑 | 波动在合理范围，平滑会改变题目给出的边界驱动 |
| 异常点 | 不删除 | 没有局部异常证据 |
| 半径平台期 | 保留原值 | 可能是真实稳定或测量分辨率，不能主观修改 |
| 单位转换 | 必须做 | cm→m、°C→K，计算内核统一 SI |
| 时间插值 | 必须做 | 附件采样步长与求解步长不同，采用分段线性插值 |
| 输出舍入 | 导出时做 | 避免中途舍入误差，最终保留四位小数 |
| 派生数据 | 不落盘 | 原始附件和代码已经足够复现 |

## 4. 敏感性结果

在问题 1 的 `t=1800 s` 上，以分段线性插值为基准：

| 处理方式 | 最大温度差 / °C | 最大水分浓度差 | 结论 |
| --- | ---: | ---: | --- |
| 前值保持 | 0.1803 | 9.76e-5 | 有可见差异，趋势不变 |
| 后值保持 | 0.1661 | 9.13e-5 | 有可见差异，趋势不变 |
| 区间中点 | 0.0029 | 1.60e-6 | 很小 |
| 4 分钟移动平均 | 0.0108 | 2.79e-6 | 很小 |
| 8 分钟移动平均 | 0.0179 | 1.25e-5 | 较小 |
| 4 分钟中值滤波 | 0.0086 | 2.48e-6 | 很小 |

结论：不做平滑或异常删除；保留分段线性插值的当前问题 1 结果。

## 5. 结果失效规则

以下任一变化都会使相关旧结果失效：

- 更换插值方式；
- 增加平滑、滤波或异常删除；
- 改变单位转换规则；
- 改变 14400 s 之后的长期边界规则；
- 改变问题 4 的半径插值或平台期处理。

失效后必须重新运行入口命令、重新导出结果文件，并重新回读关键单元格。
