## 1. 问题简述

问题 1 研究预热平衡阶段前 30 min 内，圆柱形药材在烘房热风环境中的温度和水分浓度变化。由于药材长径比较大，模型主要考察沿半径方向的传递过程。

## 2. 建模思路

可将药材视为一维轴对称圆柱体。热量由烘房空气通过对流换热传到药材表面，再由导热进入内部；水分在浓度梯度作用下由内向外扩散，并在表面通过对流传质进入空气。

## 3. 核心方程

传热方程：

`rho cp dT/dt = (1/r) d/dr(r k dT/dr)`

水分扩散方程：

`dC/dt = (1/r) d/dr(r D dC/dr)`

中心对称条件：

`dT/dr = 0, dC/dr = 0, r = 0`

表面条件：

`-k dT/dr = h(T - T_air(t))`

`-D dC/dr = hm(C - C_air(t))`

## 4. 参数与单位

- `rho = 820 kg/m3`
- `cp = 2600 J/(kg·K)`
- `k = 0.36 W/(m·K)`
- `h = 25 W/(m2·K)`
- `hm = 8e-7 m/s`
- `D = 7e-9 exp(-0.89/C) m2/s`

计算时使用 SI 单位；输出温度用 °C，水分浓度用 kg/kg。

## 5. 论文可用的模型叙述

本文首先建立预热阶段的径向传热—水分扩散模型。考虑到药材长度远大于半径，忽略两端热湿交换，将三维圆柱问题简化为沿半径方向的一维轴对称问题。内部温度场由导热方程控制，水分场由 Fick 扩散方程控制。药材中心采用对称边界，外表面采用对流换热和对流传质边界。初始温度和含水率按题目给定值取均匀分布。

## 8. 数据处理与敏感性

附件数据本身没有缺失值、重复时间戳、时间倒序或非有限值，因此本文不进行缺失插补、去重、平滑或异常点删除。温度、水分浓度和半径均保留原始数值。原始附件只读，单位转换、时间插值和输出舍入在计算流程中显式完成。

边界数据采用分段线性插值，端点外保持最后值。该处理只填补采样点之间的取值，不改变原始时刻的数据，也不引入额外的物理假设。

为检验处理方式的影响，以分段线性插值为基准，在问题 1 的 `t=1800 s` 上进行了敏感性比较：

## 9. 模型选择依据（论文写作素材）

### 9.1 可直接使用的段落

题目要求刻画圆柱形药材在预热阶段内部温度和干基水分浓度的时空变化，并给出了圆柱几何、初始状态、表面换热系数、表面传质系数、密度、比热容、导热系数以及水分扩散系数。这些变量和参数直接对应连续介质中的非稳态导热与扩散过程。因此，本文采用基于守恒定律的径向传热—水分扩散模型。

药材内部的温度变化由能量守恒和 Fourier 导热定律控制，水分浓度变化由质量守恒和 Fick 扩散定律控制。中心处由轴对称性给出零通量边界；外表面同时发生对流换热和对流传质，因此采用由题目参数 `h` 和 `hm` 决定的 Robin 边界。该推导使用了题目中给出的全部关键参数，不引入题目之外的经验参数。

选择一维径向模型有明确的几何依据。药材长 25 cm、半径 2 cm，长/半径比为 12.5。在 30 min 预热阶段内，热渗透深度约为 1.74 cm，水分渗透深度约为 0.30 cm，端部效应对中间大部分区域的影响有限，因此先用径向一维模型研究内部梯度和表面交换是合理的。

### 9.2 备选模型比较

| 备选模型 | 不采用为主模型的原因 |
| --- | --- |
| 集总参数模型 | `Bi=hR/k=1.39`，内部温度和水分梯度不可忽略 |
| 稳态模型 | `Fo=0.76`，预热阶段仍处于明显瞬态过程 |
| 直接指定表面温度或浓度 | 题目给出 `h` 和 `hm`，应采用 Robin 边界 |
| 常数扩散系数 | 附录 2 已给出 `D(C)`，应保留含水率对扩散的影响 |
| 二维或三维模型 | `L/R=12.5`，端部影响有限；复杂度明显增加但未必改变结论 |
| 含蒸发潜热的相变模型 | 题目未提供潜热和相变参数，模型不可识别 |
| 纯数据拟合或机器学习 | 附件没有内部温度和含水率观测，无法训练内部场 |

### 9.3 可验证性与边界

该模型是题目条件下最小、可识别、物理一致的基准模型。由于题目没有提供药材内部温度或含水率的实测数据，本文能够验证的是量纲一致性、初边界一致性、零驱动极限、趋势合理性、守恒误差、网格和时间步收敛以及独立实现复算；本文不声称对真实药材具有经验精度。
