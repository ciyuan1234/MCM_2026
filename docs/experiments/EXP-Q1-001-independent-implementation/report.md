## 1. 决策问题

现有隐式有限体积实现是否存在与数值实现相关的系统性错误？

零假设：独立显式有限差分结果与隐式有限体积基准在允许误差内一致。

## 2. 方法

独立实现显式有限差分求解器，不重用 `src/radial_solver.py`，在两个网格/时间步设置下运行：

- Candidate A：`dr=0.001 m`，`dt=0.25 s`；
- Candidate B：`dr=0.0005 m`，`dt=0.0625 s`；
- 高分辨率隐式参考：`dr=0.0005 m`、`dt=0.0625 s`，同一方程、同一物性、同一边界；
- 比较时刻 `100、300、600、900、1200、1500、1800 s`，比较位置 `r=0、0.5、1、1.5、2 cm`；
- 阈值：最大温度差 `<=0.01 °C`，最大水分浓度差 `<=0.001 kg/kg`。

## 3. 运行命令

```bash
python analysis/exp_q1_explicit_fdm.py --dr-m 0.001 --dt-s 0.25
python analysis/exp_q1_explicit_fdm.py --dr-m 0.0005 --dt-s 0.0625
python -m pytest tests/test_exp_q1_explicit_fdm.py -q
```

## 4. Candidate 与生产基准的直接差异

以下数字只表示独立显式解与当时生产基准 `dr=1 mm, dt=1 s` 的差别，不能单独证明收敛。

| 方案 | 最大温度差 | 最大水分浓度差 |
| --- | ---: | ---: |
| Candidate A `dr=1 mm, dt=0.25 s` | 0.01933 °C | 0.000685 kg/kg |
| Candidate B `dr=0.5 mm, dt=0.0625 s` | 0.00650 °C | 0.03351 kg/kg |

Candidate B 相对生产基准的水分差异反而更大，说明“与生产基准一致”不能作为验收标准，必须引入更细的参考解。

## 5. 同时间步下的空间网格收敛探针

固定 `dt=0.25 s`，用生产隐式求解器比较不同空间网格的表面水分浓度：

| 空间网格 | 100 s | 1800 s |
| --- | ---: | ---: |
| `dr=1.00 mm` | 2.288133 | 1.511668 |
| `dr=0.50 mm` | 2.255174 | 1.510592 |
| `dr=0.25 mm` | 2.249034 | 1.510339 |

在 100 s，相邻网格差异从 `3.30e-2` 降到 `6.14e-3`，粗网格明显尚未收敛；当时的 `result1.xlsx` 在 100 s 表面给出的 `2.28855` 接近粗网格值。

## 6. 与高分辨率参考的差异

参考解为 `dr=0.5 mm, dt=0.0625 s` 的隐式解，用于 100 s 的独立验证：

| 方案 | 最大温度差 | 最大水分浓度差 | 结论 |
| --- | ---: | ---: | --- |
| Candidate B 对高分辨率参考 | `<=0.01 °C` | `<=0.001 kg/kg` | 通过 |
| 生产基准对高分辨率参考 | 0.00198 °C | 0.03346 kg/kg | 水分不通过 |

显式稳定性指标：

| 指标 | Candidate A | Candidate B | 限制 |
| --- | ---: | ---: | ---: |
| 热稳定性 `alpha dt/dr^2` | 0.04221 | 0.04221 | < 0.5 |
| 水分稳定性 `D dt/dr^2` | 0.00123 | 0.00123 | < 0.5 |

## 7. 结论

1. 独立显式实现通过高分辨率参考验证，未发现与数值实现相关的系统性错误；
2. 基准 `dr=1 mm, dt=1 s` 的早期表面水分浓度尚未网格收敛，误差集中在最初时刻的表面薄层；
3. 仅把时间步减小到 `0.25 s`（Candidate A）不足以消除该误差，需要细化空间网格；
4. 采纳结论：生产网格细化为 `dr=0.0000625 m`（决策 G-023），细化后 `dr=0.125 mm` 对 `dr=0.0625 mm` 的最大水分差为 `3.51e-4 kg/kg`，满足用户确认的 `0.001 kg/kg` 阈值。

## 8. 本实验不覆盖的范围

- 参考解仍是数值解，不是解析解；
- 只验证问题 1 的常数物性模型，不验证问题 2 的变物性模型；
- 没有内部温度和含水率实测数据，不能声称经验精度；
- 本实验不修改主模型和主结果。
