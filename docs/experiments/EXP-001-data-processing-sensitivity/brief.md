# EXP-001：问题 1 数据处理敏感性

- 状态：已完成，非并行实验
- 日期：2026-09-11

## 决策问题

附件 1 的插值、平滑和异常处理方式是否会改变问题 1 的关键结果？

## 固定因素

- 初始温度 28 °C，初始含水率 2.55 kg/kg；
- 常数物性参数；
- 隐式有限体积；
- `dr=0.001 m`，`dt=1 s`；
- 考察时刻 `t=1800 s`。

## 候选方案

1. 分段线性插值，作为基准；
2. 前值保持；
3. 后值保持；
4. 区间中点；
5. 4 分钟移动平均；
6. 8 分钟移动平均；
7. 4 分钟中值滤波。

## 指标

- 关键节点最大温度差；
- 关键节点最大水分浓度差；
- 是否改变趋势或模型结论。

## 结果

| 方案 | 最大温度差 / °C | 最大水分浓度差 |
| --- | ---: | ---: |
| 前值保持 | 0.1803 | 9.76e-5 |
| 后值保持 | 0.1661 | 9.13e-5 |
| 区间中点 | 0.0029 | 1.60e-6 |
| 4 分钟移动平均 | 0.0108 | 2.79e-6 |
| 8 分钟移动平均 | 0.0179 | 1.25e-5 |
| 4 分钟中值滤波 | 0.0086 | 2.48e-6 |

## 停止条件与结论

- 达到“所有方案趋势一致、平滑方案影响很小”的区分条件后停止。
- 保留分段线性插值，不做平滑、插补或异常删除。
- 更换插值方式会改变四位小数结果，必须重新生成 `result1.xlsx`。
