### 2.1.1 异常点清洗辨析：为何坚持“只校验、不改值”

在常规数据预处理中，研究者往往习惯套用 $3\sigma$ 准则或四分位距（IQR）法剔除离群点。然而，烘房升温是一个典型的非平衡热力学过程，时序数据内含强烈的宏观物理升温趋势。若对原始数值直接做全局离群检测，早期的初始低温（$28^\circ\text{C}$）与后期的恒温最高温（$50.2^\circ\text{C}$）将被传统统计算法误判为“双向极端离群值”。

为此，本文转向考察其一阶离散差分序列 $\Delta X_k = X_{k} - X_{k-1}$。稳健 $Z$-score 检测显示所有差分点均满足 $|z_k| \le 3.5$，证明温湿度序列不存在传感器瞬态故障引起的物理畸变或奇异野值。附件 1 中局部约 $\pm 0.8^\circ\text{C}$ 的小幅度波动，完全符合工业干燥箱内循环热风对流与加热管启闭的真实湍流工况。若强行施加低通滤波或平滑，实质上是对真实物理输入的人为削弱。因此，本文确立\*\*“坚决不平滑、不滤波、不剔除原有点”\*\*的核心策略。

### 2.1.2 易混淆物理概念的严格解耦

在进入具体小问前，必须从量纲与物理本质上澄清两个关键数据定义，避免后续建模出现概念混淆：

1. **药材内部初始水分浓度（**$2.55\text{ kg/kg}$）：属于**多孔介质干基含水率**，表示单位绝干药材骨架质量所吸附的水分质量，是内部非稳态扩散方程中待求解的空间分布状态变量；
2. **附件 1 初始空气水分浓度（**$0.01963\text{ kg/kg}$）：属于**湿空气含湿量**，表示烘房循环热风中水蒸气与绝干空气的质量比，仅作为侧表面对流传质 Robin 边界条件中的外部环境浓度。两者分属不同相态，量级差异超百倍，绝不可混同。

## 2.2 问题一：预热阶段驱动数据的时空重构与插值选择

问题一考察烘干启动最初 $1800\text{ s}$（$30\text{ min}$）的温度与含水率剖面。此时数值求解的空间网格精度要求达到 $dr = 0.0625\text{ mm}$、时间积分步长为 $dt = 1\text{ s}$，但附件 1 的离散采样步长为 $60\text{ s}$，必须进行时间维度的亚步长数据重构。

### 2.2.1 采纳方法：分段线性插值（Piecewise Linear Interpolation）

对于任意连续求解时刻 $t \in [t_k, t_{k+1}]$，表面外部环境温度 $T_{\text{air}}(t)$ 与空气含湿量 $C_{\text{air}}(t)$ 采用分段线性内插：
$T_{\text{air}}(t) = T_k + \frac{t - t_k}{t_{k+1} - t_k} (T_{k+1} - T_k), \quad t_k \le t \le t_{k+1}$
$C_{\text{air}}(t) = C_k + \frac{t - t_k}{t_{k+1} - t_k} (C_{k+1} - C_k), \quad t_k \le t \le t_{k+1}$
分段线性插值在数学上仅引入了“相邻采样点间均匀过渡”这一**最小假设**，既完全保留了采样节点处的观测事实，又确保了插值序列在整个时间轴上的有界性、单调保凸性与非负性。

### 2.2.2 考虑但未采用的方法与量化对比论证

为证明分段线性插值相对于其他流行时序处理方法的优越性，本文设计了敏感性对照实验 EXP-001，在同等求解条件下测试了不同处理方案在 $t = 1800\text{ s}$ 时刻对状态场产生的影响。

## 2.3 问题二：恒温脱水阶段的状态依赖型非线性物性求值机制

问题二的时间跨度扩展至 $3\text{ h}$（$10800\text{ s}$），热物理物性由问题一的常数切换为附录 3 所给出的强非线性依赖公式：导热系数 $k(T, C)$、比热容 $c_p(T, C)$、干基密度 $\rho(C)$ 及局域有效扩散系数 $D(T, C)$ 均随温度与含水率产生剧烈的空间非均匀耦合演化。

### 2.3.1 采纳方法：SI 物理内核下的解析式在线动态求值

为避免不同单位换算（如 $\text{cm}$ 与 $\text{m}$、${}^\circ\text{C}$ 与 $\text{K}$）导致的隐蔽数值错误，计算内核统一采用国际标准单位制（$\text{m, s, K, kg}$）。在每个时间步的 Picard 非线性迭代中，各控制微元直接基于该网格中心当前迭代的局部温度 $T_i^m$（换算为热力学温度 $\text{K}$）与干基含水率 $C_i^m$，实时在线求取附录 3 的物性解析值：
$D_i^m = 1.4\times 10^{-4} \exp\left(-\frac{2955}{T_i^m} - \frac{0.89}{C_i^m}\right), \quad k_i^m = 0.18 + 0.32\cdot \frac{C_i^m}{1 + C_i^m}$
$c_{p,i}^m = 1350 + 2800\cdot \frac{C_i^m}{1 + C_i^m}, \quad \rho_i^m = \frac{480}{1 - 0.28\cdot \frac{C_i^m}{1 + C_i^m}}$

### 2.3.2 考虑但未采用的方法与弃用机理分析

1. **弃用“离线状态二维查表 + 双线性空间插值（Lookup Table Method）”**：

   * *初衷*：传统工程仿真常通过预先计算 $(T, C)$ 离散网格上的物性格点，运行时查表双线性插值以减少指数运算耗时。

   * *弃用原因*：现代高性能科学计算中矢量化解析求值耗时极低（单步仅需微秒级）。更关键的是，附录 3 中的 Arrhenius 型扩散系数在低含水率区域呈现极强烈的负指数陡峭衰减。查表网格若不够密集，双线性插值会带来不可忽视的截断误差，且无法准确刻画药材表层在水分快速脱附时形成的局部“干缩硬壳”物性突变。
2. **弃用“时间/空间分段全局均值物性近似法”**：

   * *初衷*：若将某一时间段内的平均温湿度代入物性，可将复杂的非线性 PDE 退化为拟线性方程求解。

   * *弃用原因*：在 3 小时恒温烘干过程中，药材表层含水率迅速从 $2.55\text{ kg/kg}$ 暴跌至 $1.008\text{ kg/kg}$，扩散系数跨越数倍变化。均值化处理会人为抹平内外传质阻力的巨大差异，掩盖“表面扩散受阻、内部水分难以析出”的核心干燥瓶颈。

## 2.5 问题四：时变几何收缩下的移动边界处理与坐标映射

问题四引入了药材失水体积收缩机制，附件 2 记录了药材截面半径 $R(t)$ 在 $72\text{ h}$ 内从 $2.000\text{ cm}$ 不断萎缩至 $1.198\text{ cm}$ 的离散演化轨迹（采样间隔 $1800\text{ s}$）。

### 2.5.1 采纳方法：材料坐标归一化变换（Material Coordinate Transformation）

药材半径连续动态萎缩使得传热传质的外边界 $r = R(t)$ 成为强时变函数。若在欧拉空间采用动网格，频繁的网格重剖分（Remeshing）与多场重插值会在长达上万个时间步的积分中累积显著的数值耗散，破坏代数质量守恒。

为此，本文引入拉格朗日型**材料归一化坐标**：
$\xi = \frac{r}{R(t)} \in [0, 1]$
在该坐标系下，计算物理域被永久固定在静态单位区间 $[0, 1]$ 上。由于干基含水率 $C$ 的物理基准为“单位绝干骨架固体质量”，在脱水萎缩过程中，药材固相骨架微元在材料坐标中相对静止（物质导数等于偏导数），因而方程中无需引入任何非物理的流体对流项，仅需在空间导数中乘入几何缩放因子 $1/R(t)^2$。对于任意时刻的半径 $R(t)$，直接对附件 2 进行分段线性插值。

1. **有力回击“强行平滑数据”的建模陋习**：附件 2 中由于测量分辨率原因存在长达 92 个时间步的恒定不变平台。实验证实，强行采用保单调样条平滑消除该平台，对最终烘干时间的影响仅为 $+0.0132\text{ h}$（不到 1 分钟）。这强有力地证明了基准模型对原始实测采样台阶的高鲁棒性，无需引入主观设定的平滑滤波超参数；
2. **揭示“动态收缩不可替代性”的重大工程价值**：简化论者常倾向于直接采用最终脱水尺寸（$1.198\text{ cm}$）作为常数半径求解以简化模型。然而，EXP-003 的消融数据发出了明确警示：**忽略收缩的动态演化过程将导致烘干时间被大幅低估 3.2820 小时（相对偏差高达 6.5%）！** 这是因为在烘干前中期的大部分时间内，药材均保持着较大的几何截面，其核心到表面的扩散路径与质量阻力远大于终态尺寸。若工程上据此停机，将导致药材核心严重未烘透而发生霉变。这一对比雄辩地证明了本文构建时变移动边界模型的必要性与工程严谨性。

## 2.6 数据处理失效规则与可复现性防线

为确保本模型的所有推导与交付结论具备可溯源性与同行可复现性，本文明确制定以下\*\*“数据处理结果失效规则”\*\*。一旦下述任一前置处理假设发生变更，本研究所导出的所有结果文件与数据结论即刻宣告失效，必须重新执行自动化计算管道：

1. **插值准则变更**：若将温湿度或半径的分段线性插值变更为高阶样条插值或阶梯保持；
2. **平滑引入**：若在输入层重新引入任何低通滤波、小波去噪或移动平均；
3. **长期边界重设**：若修改 $t > 14400\text{ s}$ 的平稳末值设定方式；
4. **移动边界坐标重构**：若推翻材料坐标体系改用欧拉动网格对流方程。
